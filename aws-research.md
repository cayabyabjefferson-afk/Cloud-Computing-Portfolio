Brief Overview

Amazon Web Services (AWS) is a cloud computing platform provided by Amazon. It offers many services that organizations can use to run applications, store data, manage networks, analyze information, and build artificial intelligence solutions without maintaining all physical infrastructure themselves.

AWS is widely used by startups, businesses, government organizations, and large enterprises.

Global Infrastructure

AWS operates a worldwide infrastructure made up of Regions and Availability Zones.

Region – a geographic area containing AWS infrastructure.
Availability Zone (AZ) – an isolated location within an AWS Region.
Multiple Availability Zones help organizations design applications with high availability and fault tolerance.
Cloud Management Console

The AWS Management Console is a web-based interface for accessing and managing AWS services. Users can create virtual machines, configure storage, manage users, monitor resources, and control cloud infrastructure through the console.

Four Core Services
1. Amazon EC2

Amazon Elastic Compute Cloud (EC2) provides virtual servers that can run applications and operating systems in the cloud.

2. Amazon S3

Amazon Simple Storage Service (S3) provides object storage for files, images, videos, backups, documents, and other data.

3. Amazon VPC

Amazon Virtual Private Cloud (VPC) allows users to create logically isolated networks and configure networking resources such as subnets, routing, and security controls.

4. AWS IAM

AWS Identity and Access Management (IAM) controls who can access AWS resources and what actions they are allowed to perform.

Three Advantages
Large service portfolio – AWS provides a very broad range of cloud services.
Scalability – resources can be increased or decreased according to workload requirements.
Global infrastructure – AWS provides infrastructure across many geographic locations.
