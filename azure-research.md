Brief Overview

Microsoft Azure is Microsoft's cloud computing platform. It provides cloud services for computing, storage, networking, databases, security, artificial intelligence, and application development.

Azure is particularly useful for organizations that already use Microsoft technologies such as Windows Server, Microsoft 365, and Microsoft Entra ID.

Global Infrastructure

Azure operates a global infrastructure consisting of geographies, regions, and availability zones.

Azure Regions contain datacenters located in specific geographic areas. Availability Zones provide physically separate locations within supported regions to improve application availability and resilience.

Cloud Management Console

The Azure Portal is a web-based management interface for Azure resources. Administrators can create virtual machines, configure networks, manage storage, monitor applications, and manage identities through the portal.

Four Core Services
1. Azure Virtual Machines

Azure Virtual Machines provide scalable virtual servers for running Windows or Linux operating systems and applications.

2. Azure Blob Storage

Azure Blob Storage is Microsoft's object storage service. It can store large amounts of unstructured data such as documents, images, videos, and backups.

3. Azure Virtual Network

Azure Virtual Network (VNet) allows cloud resources to communicate securely and provides networking features such as subnets and routing.

4. Microsoft Entra ID

Microsoft Entra ID is Microsoft's cloud identity and access management service. It helps organizations manage users, applications, authentication, and access to resources.

Note: Microsoft Entra ID was formerly called Azure Active Directory (Azure AD).

Three Advantages
Microsoft integration – works well with Windows Server, Microsoft 365, and other Microsoft technologies.
Hybrid cloud capabilities – supports organizations that need to connect on-premises systems with cloud resources.
Enterprise features – provides extensive security, identity, management, and compliance capabilities.
