# Laboratory 05 - Cloud Data Engineer

## Mission Overview

In this laboratory, I explored cloud storage technologies and deployed an object storage server using MinIO. The activity focused on understanding different types of cloud storage and applying Docker skills to create and manage an S3-compatible object storage environment.

## Objectives

* Understand the three primary types of cloud storage: Block Storage, File Storage, and Object Storage.
* Compare the uses and characteristics of different cloud storage types.
* Deploy MinIO using Docker.
* Configure MinIO using environment variables.
* Access the MinIO Web Console.
* Create an object storage bucket.
* Upload a sample file to the bucket.
* Document the deployment and storage configuration.

## Tools Used

* **KillerCoda Ubuntu Playground** – Used as the Linux environment for the laboratory.
* **Docker** – Used to deploy and run the MinIO container.
* **MinIO** – Used as the S3-compatible object storage server.
* **GitHub** – Used to document and submit the laboratory work.
* **Web Browser** – Used to access the MinIO Web Console.
* **Sample Image/Text File** – Used to test file uploading to the object storage bucket.

## Skills Learned

* Using Docker commands to deploy applications.
* Pulling and running container images.
* Mapping container ports to host ports.
* Using environment variables to configure a container.
* Verifying running containers with `docker ps`.
* Accessing a web-based cloud storage console.
* Creating and managing object storage buckets.
* Uploading objects to a cloud storage bucket.
* Documenting technical deployment procedures using Markdown.
