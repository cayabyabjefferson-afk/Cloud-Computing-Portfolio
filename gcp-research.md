Brief Overview

Google Cloud Platform (GCP), commonly called Google Cloud, is Google's cloud computing platform. It provides services for computing, storage, databases, networking, data analytics, artificial intelligence, and application development.

Google Cloud is particularly well known for its data analytics, artificial intelligence, and Kubernetes technologies.

Global Infrastructure

Google Cloud operates a global infrastructure organized into regions and zones.

Region – a geographic location where Google Cloud resources are hosted.
Zone – an isolated deployment area within a region.
Resources can be distributed across zones to improve availability and resilience.
Cloud Management Console

The Google Cloud Console is a web-based interface for managing Google Cloud resources. Users can create virtual machines, configure networks, manage storage, monitor applications, and manage identities.

Four Core Services
1. Compute Engine

Compute Engine provides virtual machines that can run Linux, Windows, and other workloads.

2. Cloud Storage

Cloud Storage is Google's object storage service. It can store files, backups, media, datasets, and other unstructured data.

3. Google Cloud VPC

Google Cloud Virtual Private Cloud (VPC) provides networking capabilities for cloud resources, including subnets, routing, and network security.

4. Google Kubernetes Engine (GKE)

Google Kubernetes Engine (GKE) is a managed Kubernetes service for deploying and managing containerized applications.

For your assignment, you could alternatively research Cloud Identity as the fourth core service if you want your GCP services to correspond more directly with AWS IAM and Microsoft Entra ID.

Three Advantages
Strong AI and machine learning capabilities – Google has extensive technologies for data and AI workloads.
Kubernetes expertise – Google created Kubernetes and provides GKE as a managed Kubernetes platform.
Data analytics – Google Cloud provides powerful services for processing and analyzing large datasets.
